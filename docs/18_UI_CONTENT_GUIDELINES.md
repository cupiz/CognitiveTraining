# 18 — UI & Content Guidelines

## Parent language

Use:
- "performance"
- "training progress"
- "practice consistency"
- "task performance"
- "recent trend"

Avoid:
- "brain age"
- "brain damage"
- "neurological weakness"
- "IQ increased"
- "your child has ADHD"
- "fixes attention disorder"

unless a qualified clinical/research workflow explicitly supports a claim and legal/scientific review approves it.

## Child language

Good:
- "Great focus!"
- "Ready for the next round?"
- "Let's try another one."

Avoid:
- "You failed."
- "Your memory is bad."
- "You're slower than other kids."

## Result display

Example:
```text
Today's training
✓ Memory Matrix
✓ Target Watch
✓ Rule Switch

You completed 12 minutes of training.

This week:
Accuracy: improving
Response consistency: stable
```

## Flagship copy (proposal)

Child instructions (short, spoken, ID first):
- Spice Stall — ID: "Ingat pesanan pelanggan, lalu racik dengan urutan yang
  sama sebelum waktunya habis." EN: "Remember the order, then rebuild it in
  the same order before time runs out."
- Red Light — ID: "Lari saat lampu hijau, berhenti total saat lampu merah."
  EN: "Run on green, freeze on red."
- Courier Map — ID: "Antar paket ke bendera mengikuti aturan yang aktif."
  EN: "Deliver the package to the flag following the active rule."
- Lighthouse Keeper — ID: "Ulangi urutan pancaran mercusuar di kaca pelita."
  EN: "Repeat the lighthouse's colour sequence on the lantern panes."
- Sushi Express — ID: "Tangkap piring sushi yang dipesan sebelum lewat."
  EN: "Catch the ordered sushi plates before they slide past."
- Crystal Palace — ID: "Temukan semua kristal yang cocok dengan contohnya."
  EN: "Find every crystal that matches the target."

Parent report sentences (task performance only):
- Spice Stall — "Akurasi mengingat urutan pesanan: {x}% ({trend})."
- Red Light — "Berhasil menahan diri saat lampu merah: {x}% ({trend})."
- Courier Map — "Paket sampai: {n}/{m}; kesalahan aturan: {k} ({trend})."
- Lighthouse Keeper — "Akurasi mengulang urutan pancaran: {x}% ({trend})."
- Sushi Express — "Pesanan tersaji tepat: {x}% ({trend})."
- Crystal Palace — "Kristal yang ditemukan tepat: {x}% ({trend})."

Failure copy stays kind: "Belum pas — coba lagi ya." Never rank children
against each other.

## Disclaimers

Parent dashboard should clearly explain:
- training is not diagnosis
- performance varies
- scores are estimates
- progress may include practice effects
- professional evaluation is appropriate for health/learning concerns
